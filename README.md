# E-Commerce Sales Dashboard

An interactive Power BI dashboard designed to analyze e-commerce sales, profitability, products, platforms, countries, and business performance.

## 📊 Dashboard Preview

![E-Commerce Sales Dashboard](Screenshots/ecommerce-sales-dashboard.png)

## 📌 Project Overview

This project uses Microsoft Power BI to analyze e-commerce sales data and provide an interactive view of sales and profitability.

The dashboard helps analyze:

- Total sales
- Gross profit
- Profit margin
- Units sold
- Orders
- Product performance
- Category performance
- Platform performance
- Country-level performance
- Sales and profit trends

## 🎯 Objectives

- Analyze overall e-commerce sales performance.
- Monitor revenue and gross profit.
- Identify top-performing products.
- Compare different e-commerce platforms.
- Analyze country-level sales performance.
- Understand product category contribution.
- Track sales and profit trends over time.

## 📈 Key KPIs

- Total Sales
- Gross Profit
- Profit Margin
- Units Sold
- Total Orders

## 📊 Dashboard Features

### Sales Performance

Provides an overview of sales, gross profit, profit margin, units sold, and total orders.

### Platform Analysis

Compares revenue and gross profit across different e-commerce platforms.

### Product Analysis

Identifies top-performing products based on sales performance.

### Category Analysis

Shows the contribution of different product categories.

### Country Analysis

Provides a geographical view of sales and business performance.

### Trend Analysis

Shows how revenue and gross profit change over time.
